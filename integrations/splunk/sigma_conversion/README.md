# SIEM Connector Interface + Sigma to SPL Conversion

## Overview
Converts fine-tuned model Sigma rules into executable Splunk SPL queries
using pySigma, with automatic rule fixing and validation.

This is part of the Autonomus Threat Hunting Platform pipeline:
Hypothesis → Fine-tuned LLM → Sigma Rule → pySigma → SPL → Splunk

## Fixes Applied Automatically
| Problem                  | Fix Applied                        |
|--------------------------|------------------------------------|
| Invalid UUID             | Auto-generated valid UUID v4       |
| Empty CIDR fields        | Removed empty fields               |
| Duplicate list items     | Deduplicated automatically         |
| Truncated list items     | Removed incomplete values          |
| Empty selection block    | Replaced with dummy EventID: 1     |
| Missing condition field  | Added default: condition: selection|

## How to Run

Step 1 - Install requirements:
    pip install pysigma
    pip install pysigma-backend-splunk

Step 2 - Make sure eval_results.json is in the same folder as 56.py

Step 3 - Run the script:
    python 56.py

Step 4 - Check the output:
    spl_results.json will be created with all SPL queries

## Output Format
Each entry in spl_results.json contains:

    {
      "example_id": 0,
      "technique_id": "T1571",
      "sigma": "title: Suspicious C2 Communication...",
      "spl": "DestinationHostname IN (*.discord.com, ...)",
      "spl_valid": true,
      "error": null
    }

## Example

INPUT (Sigma Rule):
    title: Suspicious C2 Communication
    logsource:
      category: network_connection
      product: windows
    detection:
      selection:
        DestinationHostname|endswith:
        - .discord.com
        - .telegram.org
      condition: selection
    level: medium

OUTPUT (SPL Query):
    DestinationHostname IN ("*.discord.com", "*.telegram.org")
