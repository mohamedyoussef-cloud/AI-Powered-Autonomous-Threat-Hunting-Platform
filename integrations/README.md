# SIEM integration boundaries

Research SIEM conversion and validation adapters, plus placeholders for other SIEM vendors.

## Contents
- [`elastic/`](elastic/) — reserved integration boundary without a tracked Elastic connector implementation.
- [`sentinel/`](sentinel/) — reserved integration boundary without a tracked Sentinel/KQL connector implementation.
- [`splunk/`](splunk/) — legacy prototype code for Sigma-to-SPL translation and a query safety gate.

## Interpretation and usage

The recorded end-to-end runtime evidence is Splunk-oriented. Empty Elastic and Sentinel directories do not imply implemented or tested connectors.
