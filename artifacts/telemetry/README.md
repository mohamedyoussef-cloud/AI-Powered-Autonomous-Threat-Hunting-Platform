# Canonical telemetry research outputs

Normalized source inventories, resolved data-component relationships and technique-level evidence summaries.

## Contents
- [`canonical/`](canonical/) — normalized telemetry capability/evidence inventories produced by the pipeline.
- [`resolved/`](resolved/) — resolved source-to-capability mapping evidence produced by the research pipeline.

## Interpretation and usage

Telemetry evidence informs whether a planned Sigma/SPL detection can be executed; it must not be equated with actual ingested alerts.
